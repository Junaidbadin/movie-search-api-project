# movie-search-api-project

A simple web application that allows users to search for movies using the OMDb API (or your used API). Built with HTML, CSS, and JavaScript.

# Features
 Search movies by title
 Fetch movie details from API
 Responsive UI

# Technologies Used
HTML5
CSS3
JavaScript (Vanilla)
[https://www.tvmaze.com/api] (`https://api.tvmaze.com/search/shows?q=${query}`)

# Purpose
This project was created as a hands-on mini project to understand how APIs work. It helped me learn how to:

 Send API requests and handle responses using JavaScript.
 Work with asynchronous code (promises and `fetch()`).
 Dynamically update the DOM based on user input.
